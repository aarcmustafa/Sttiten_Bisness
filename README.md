# Stitten Stores 2.0

تطبيق ويب وموبايل مبني بـ Flutter لإدارة المتاجر وتسيير الكريدي والموردين بدقة وسهولة.

## المطور
* **المصمم والمبرمج:** جلولي مصطفى

## المميزات الرئيسية
* إدارة الموردين والفواتير.
* تسيير حسابات الزبائن والموظفين وتنبيهات المواعيد.
* حساب الصندوق والأرباح الشهرية.
* حماية التطبيق برمز PIN ونسخ احتياطي كامل.
